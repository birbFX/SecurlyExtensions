# SecurlyExtensions

A collection of Securly browser extension files retrieved from a Securly update manifest.

## Contents

This repository contains files associated with Securly browser extensions, including extension resources and manifests where available.

## Purpose

This repository is intended for **research, archival, and educational purposes**, such as examining how Securly browser extensions are structured and distributed.
